# 7thStreetSalon

Hair Salon Website built with React, TypeScript, Vite, TanStack Router, and Tailwind CSS.

## Tech Stack

- React 19
- TypeScript
- Vite
- TanStack Router
- Tailwind CSS

## Development

Install dependencies:

```bash
npm install
```

Run the dev server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```
